# Hassani Offline Chat — starter

This is a starter Flutter app and a GitHub Actions workflow for building a debug APK in the cloud.

## Important limitation
This starter currently contains a sample chat interface and local in-app messages only. It does **not** yet implement real device-to-device offline communication, Wi-Fi/Bluetooth discovery, voice messages, image transfer, or secure group messaging. Do not treat it as a finished messenger.

## Build workflow
1. Upload all files and folders from this ZIP to your GitHub repository, keeping their folder structure.
2. In GitHub, open **Actions**.
3. If prompted, enable workflows.
4. Choose **Build Android APK** and press **Run workflow**.
5. When the run finishes successfully, open the run and download the `hassani-offline-chat-apk` artifact.
